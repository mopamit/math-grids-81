# המרחב המתמטי — חבילה מלאה ומוכנה לפרסום

החבילה כוללת:

- `docs` — האתר המוכן לפרסום ב־GitHub Pages.
- `source` — קוד המקור המלא להמשך פיתוח.

## העלאה ל־GitHub

1. העלו לשורש המאגר את התיקיות `docs` ו־`source` בשלמותן.
2. החליפו את התיקיות הקיימות; אל תערבבו את תוכן `docs` עם גרסה קודמת.
3. ב־GitHub פתחו `Settings` ואז `Pages`.
4. בחרו `Deploy from a branch`, ענף `main`, ותיקייה `/docs`.

פלט הפרסום משתמש בנתיבי `assets` יחסיים, ולכן אינו תלוי בשם המאגר.

## השינויים בגרסה זו

- פונקציות יכולות להיכתב כ־`y=...`,‏ `f(x)=...`,‏ `g(x)=...` וכן הלאה.
- סימון מדידות מתמטי: `m=` לשיפוע, `d=` לאורך או מרחק, `r=` לרדיוס, `p=` להיקף ו־`s=` לשטח.
- מעגלים נוצרים בלי רדיוס, קוטר, היקף או שטח גלויים כברירת מחדל.
- במעגל מרכז ונקודה מוצגת נקודת השפה בזמן התצוגה המקדימה.
- מקביל ומאונך מאפשרים לבחור נקודה קיימת או ליצור נקודה חדשה בלחיצה.
- חוצה זווית ניתן לבנות מזווית קיימת או משתי שוקיים והקודקוד המשותף.
- העיגול בסרגל האובייקטים משמש להצגה ולהסתרה של האובייקט.
- שמות בניות מוצגים בסדר קריא, למשל `מקביל ל־BC`.
