# המרחב המתמטי — גרסה מורחבת

סביבת עבודה אינטראקטיבית בעברית לבנייה גאומטרית, מדידה וחקירת פונקציות. החבילה מוכנה לפרסום ב־GitHub Pages.

## סביבת העבודה

- **בנייה ומדידה** — נקודות, קטעים, ישרים, זוויות, מצולעים ומעגלים.
- **גרפים ופונקציות** — פונקציות קוויות, ריבועיות וכלליות, מחוונים דינמיים והגבלת תחום.
- **חקירה משולבת** — כל הכלים יחד.
- כל קבוצת כלים נפתחת ונסגרת בנפרד כדי לשמור על ממשק נקי.

## יכולות עיקריות

- מצולעים דינמיים עם אורכי צלעות, זוויות, היקף ושטח.
- מעגל לפי מרכז ונקודה, מרכז ורדיוס או שלוש נקודות; רדיוס, היקף ושטח.
- נקודת אמצע, מקביל, מאונך, אנך אמצעי, תיכון וחוצה זווית.
- נקודות חיתוך בין ישרים, מעגלים ופונקציות.
- פונקציות עם תחום מוגבל וקצוות פתוחים או סגורים.
- מחוונים דינמיים המשתלבים בביטויים כגון `y=a*x^2`.
- טבלת ערכים אופציונלית לכל פונקציה.
- שיקוף, סיבוב והזזה של אובייקטים.
- ביטול וביצוע מחדש, הצמדה לרשת, שינוי שנתות וייצוא PNG.

## מבנה המאגר

- `docs` — האתר המוכן לפרסום.
- `source` — קוד המקור המלא להמשך פיתוח.

## פרסום ב־GitHub Pages

1. העלו את תוכן החבילה למאגר בשם `math-Hinge-system-81`.
2. פתחו `Settings` ואז `Pages`.
3. בחרו `Deploy from a branch`.
4. בחרו בענף `main` ובתיקייה `/docs`.
5. לחצו `Save`.

כתובת האתר תהיה:

`https://mopamit.github.io/math-Hinge-system-81/`

## הפעלה מקומית — אופציונלי

```bash
cd source
npm install
npm run dev
```
