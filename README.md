# המרחב המתמטי — math-grids-81

חבילה מלאה לפרסום ב־GitHub Pages.

## העלאה

יש להחליף בריפו את התיקיות `docs` ו־`source` בשלמותן בתיקיות שבחבילה.
בהגדרות GitHub Pages יש להשאיר את הענף `main` ואת התיקייה `/docs`.

## התיקונים בגרסה זו

- עודכנה רק פריסת המקלדת המתמטית; כלי הגאומטריה והבניות נשארו ללא שינוי.
- לוח המספרים הוא 3×4: בשורה התחתונה `0`, נקודה ו־`=`.
- פעולות החיבור, החיסור, הכפל והחילוק מוצגות בטור צמוד למספרים.
- המשתנים `x` ו־`y`, הפעולות הנפוצות והמבנים המתמטיים מחולקים לקבוצות ברורות.
- כפתור "מתקדם" פותח פונקציות, טריגונומטריה, חשבון דיפרנציאלי ואינטגרלי ומטריצות.
- מלבן העריכה וכפתורי העריכה נשארו כפי שהיו.
- מחוונים דינמיים מזוהים כעת גם כאשר אות המחוון צמודה למשתנה, למספר,
  לסוגריים או לפונקציה, למשל `ax+b`, `2a+x`, `a(x+1)` ו־`a*sin(x)`.
- תיקון המחוונים הוחל על גרסת `FINAL-KEYBOARD-FIX`, ללא ביטול תיקוני המקלדת
  והבניות שכבר נכללו בה.
- שדות המספר בחלונית מאפייני האובייקט הוגדלו וקיבלו כפתורי `−` ו־`+`
  ברורים, עם תמיכה נוחה בהקלדת מספרים שליליים.
- תצוגת קצות התחום, עובי הקו וסגנון הקו סודרה והוגדלה לקריאות טובה יותר.
