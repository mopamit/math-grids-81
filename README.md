# המרחב המתמטי — הגרסה המלאה והמורחבת

חבילה מלאה ומוכנה לפרסום ב-GitHub Pages.

הגרסה נבנתה על בסיס הגרסה האחרונה שעבדה ושומרת על מרחב העבודה החופשי: התלמיד יוצר בעצמו נקודות, קטעים, ישרים, זוויות, צורות ופונקציות. כלי המשוואה כולל מקלדת מתמטית חזותית המבוססת על MathLive.

## היכולות המרכזיות

- שלוש סביבות: בנייה ומדידה, גרפים ופונקציות וחקירה משולבת.
- קבוצות כלים מתקפלות כדי לצמצם עומס.
- נקודות, קטעים, ישרים, זוויות, מצולעים ושלושה סוגי בניית מעגל.
- נקודת אמצע, מקביל, מאונך, אנך אמצעי, תיכון וחוצה זווית.
- חיתוכים בין ישרים, קטעים, מעגלים ופונקציות.
- מדידות של אורך, שיפוע, זווית, היקף, שטח, רדיוס וקוטר.
- פונקציות קוויות, ריבועיות וכלליות עם אימות הסוג שנבחר.
- מחוונים דינמיים, תחום פתוח או סגור וטבלת ערכים.
- נקודה על גרף שנשארת מחוברת לגרף גם כאשר מחוון משתנה.
- הזזה, סיבוב ושיקוף של אובייקטים.
- שינוי שם, צבע, עובי וסגנון, הצגה והסתרה ומחיקה בטוחה של אובייקטים תלויים.
- ביטול, ביצוע מחדש, איפוס תצוגה, עבודה חדשה וייצוא PNG.

## מבנה המאגר

- `docs` — האתר המוכן לפרסום. אין צורך לבנות או לשנות אותו.
- `source` — קוד המקור המלא להמשך הפיתוח.

## פרסום

לאחר העלאת כל תוכן החבילה למאגר:

1. פתחו `Settings`.
2. בחרו `Pages`.
3. תחת `Build and deployment`, בחרו `Deploy from a branch`.
4. בחרו בענף `main` ובתיקייה `/docs`.
5. לחצו `Save`.

גרסת `docs` מיועדת למאגר ששמו `math-Hinge-system-81` ושומרת את תיקיית `_next` המקורית של Next.js. הקובץ `.nojekyll` שבתיקיית `docs` הכרחי לפרסום תקין ב־GitHub Pages, ולכן יש להעלות גם אותו.

אין צורך ב-GitHub Actions, ב-Node.js, ב-npm או בתיקיות נסתרות.

## הפעלת קוד המקור במחשב — אופציונלי

```bash
cd source
npm install
npm run dev
```
