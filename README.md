# Prismind – גרסה בטוחה ל־GitHub Pages

החבילה בנויה כך שקובץ `index.html` נמצא בשורש, וקובצי האתר נמצאים בתיקייה
`site-assets` שאינה מתחילה בקו תחתון. לכן אין תלות ב־`.nojekyll` ואין צורך
להגדיר תיקיית `docs`.

## העלאה לריפו חדש

1. חלצו את קובץ ה־ZIP.
2. העלו את **כל התוכן שבתוך התיקייה שחולצה** לשורש הריפו.
3. ב־GitHub עברו אל `Settings → Pages`.
4. בחרו `Deploy from a branch`, אחר כך `main` ו־`/(root)`.
5. שמרו והמתינו לסיום הפרסום.

התיקייה `source-code` מכילה את קוד המקור ואינה נדרשת להפעלת האתר.
